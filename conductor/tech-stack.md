# Technology Stack

## Core Technologies
- **TypeScript:** The primary programming language for both the theme engine and the CLI.
- **RevealJS:** The underlying presentation framework.
- **Lit-html:** Used for efficient HTML templating within the theme's logic.
- **Sass (SCSS):** The CSS preprocessor used for styling and theme variables.

## Build and Development
- **Vite:** Used for building the theme and managing the demo environment.
- **tsup:** Used for bundling the CLI and scripts into efficient, standalone files.
- **TSC:** The TypeScript compiler for type checking and transpilation.
- **Node.js:** The runtime environment for development scripts and the CLI.

## Quality Assurance
- **Vitest:** The testing framework for unit and integration tests.
- **ESLint:** Used for linting and enforcing code style (configured in `eslint.config.mjs`).
- **Prettier:** Used for automated code formatting.
